# cybersecurity-portfolio
This is a digital forensics portfolio that will showcase my projects and tools I have used so far throughout digital forensics 1. I will continue to add on throughout Digital Forensics 2. 
Skills Learned

- Advanced research into cases.
- Creating forensic images while preserving data integrity and maintaining a strict chain of custody.
- Carving files, analyzing file system metadata, and investigating system logs to reconstruct events.
- Capturing and analyzing network packets to detect unauthorized access or malicious activity.
- Synthesizing technical findings into structured documentation suitable for audit or legal review.

Tools Used

Autopsy [autopsy.com](https://www.autopsy.com) Open-source platform for hard drive forensic analysis.
Wireshark [wireshark.org](https://www.wireshark.org) Network protocol analyzer for inspecting packet data. 
FTK Imager [exterro.com](https://www.exterro.com) Forensic tool for acquiring digital evidence copies. 
Volatility [volatilityfoundation.org](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fwww.volatilityfoundation.org) Open-source memory forensics framework for analyzing volatile memory (RAM) dumps to uncover malware and active processes.
